Findings

High — Social response validation still rejects values allowed by the exact public schemas.

- WHAT: The CLI validates social connection `url` and post `platformPostUrl` with `z.url()`, while the current Viewpress response schemas deliberately use `z.string()`. A server-valid response can therefore become `invalid_response`.
- WHERE: `src/commands/run-social.ts:22` and `src/commands/run-social.ts:40`. The source contracts are `/Users/mike/Code/viewpress/src/app/api/v1/social/accounts/connections/route.ts:23` and `/Users/mike/Code/viewpress/src/lib/api/public-social-post.ts:20`.
- WHAT GOOD LOOKS LIKE: Under the exact-response-schema rule, parse both fields as strings. Apply URL restrictions only at a client action boundary that actually navigates or downloads; these values are currently returned or printed.

Medium — The server-contract inventory does not describe asynchronous social connection correlation.

- WHAT: Account connection creation returns only a browser URL and instructions. The account row appears asynchronously after the callback, but there is no attempt id, attempt-status endpoint, or structured callback failure available to the CLI. The existing “Social account correlation” section discusses post ownership and connection lookup instead of this connection-attempt gap.
- WHERE: `docs/server-contracts.md:104` and `docs/api.md:155`. Server evidence is `/Users/mike/Code/viewpress/src/app/api/v1/social/accounts/connections/route.ts:19` and the platform callback routes under `/Users/mike/Code/viewpress/src/app/oauth/*/callback/route.ts`.
- WHAT GOOD LOOKS LIKE: Under the unsupported-server-requirements rule, document a precise account-connection attempt contract: creation returns an opaque attempt id, an account-scoped status endpoint exposes pending/connected/denied/expired/error, success identifies the new connection, and callback errors remain queryable. State that today the CLI can only return the URL and users must compare or poll the account list without reliable correlation.

Medium — The lean suite still uses permissive request matching and retains redundant negatives.

- WHAT: The social post integration uses recursive `toMatchObject`, so unexpected request fields or platform envelopes can pass. It also includes a social wait timeout; the asset terminal test includes another timeout; and the partial-download test also checks existing-output refusal. These exceed the user’s named minimum negative set.
- WHERE: `test/social.test.ts:87`, `test/social.test.ts:129`, `test/assets.test.ts:162`, and `test/assets.test.ts:177`.
- WHAT GOOD LOOKS LIKE: Under the test-count clarification, compare the social request sequence and bodies exactly with `toEqual`, especially `options` and `publish_at`. Keep only credential storage/leakage, unexpected auth/browser hosts, external-download auth, truncated cleanup, and one terminal-failure negative. Remove duplicate wait-timeout and existing-output cases instead of adding tests.

Low — Parser splitting remains incomplete in the reviewed territory.

- WHAT: Several functions still combine iteration, state mutation, validation, and construction across roughly 36–60 lines.
- WHERE: `src/commands/run-assets.ts:146` (`getListOptions`), `src/commands/run-assets.ts:552` (`removeBackground`), `src/commands/run-assets.ts:605` (`enhanceAudio`), and `src/commands/run-video-style-tool.ts:486` (`getTimelapseOptions`).
- WHAT GOOD LOOKS LIKE: Under the short-function rule, finish the command-local reader pattern already introduced by commit `86dd3b3`: separate argument reading from validation/result construction without introducing a shared parser framework.

Low — Download command help omits supported JSON file output.

- WHAT: `assets download --help` lists only `--force`, while the command reference and runtime support global `--json` when output is a file.
- WHERE: `src/commands/run-assets.ts:825`; verified in the compiled native binary. The documented behavior is `docs/commands.md:216`.
- WHAT GOOD LOOKS LIKE: Under help/runtime consistency, include `[--json]` in download command help and state that it is unavailable with `--output -`, matching the existing runtime rule.
